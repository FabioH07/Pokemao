# Pokemao

Servidor de Cobblemon com os crias

# Instalação

### 1 º Baixar o prism launcher (v11.0.3 ou mais recente, se tiver minecraft original pode baixar o launcher original)

    https://github.com/Diegiwg/PrismLauncher-Cracked/releases/download/11.0.3/PrismLauncher-Windows-MinGW-arm64-11.0.3.zip

video tutorial de instalação : https://drive.google.com/file/d/11WDNGIT8sClYzF0zmld1dk8hZ2grz8wT/view?usp=drive_link

### 2 º Instalar o mod pack

baixe o arquivo .mrpack do modpack em: https://drive.google.com/drive/folders/1f2Y3S4azJqb7lT7GrB_6qPMPM3dvTEQe?usp=drive_link

![Pasted image 20260728220852.png](Pasted%20image%2020260728220852.png)

3º Com o Prism Launcher aberto clique em Add Instance -> Import -> cole o caminho de onde você salvou o modpack. Aceite todas as dependencias.

4º Acessar o server pelo endereço car-interactions.gl.joinmc.link 


# Regras do Servidor 

	Não vacalhem com os colegas e se divirtão.

# Regras dos torneios 
	O ideal seria todos respeitarem as regras de torneio / level cap.
	Pokemons lendarios ou pegos fora do level cap estão proibidos
	Gigantamax, Mega e terralith estão bloqueados.
	É proibido usar consumiveis durante o torneio com exeção aos que vão equipados nos pokemons.
	Também é proibido trocar o time e ataques dos pokemons durante o torneio.
